# User Guide

> Written for Bharti Enterprises staff. Grows with each module; finalized in Phase 11.

## Signing in

Open the app link on any phone, tablet or computer browser. Enter the username and
password given by the Admin. First sign-in asks you to set a new password.

Roles:
- **Admin** — full control, user management, updates, corrections.
- **Operator** — daily data entry (purchases, cutting, jobs, receipts, checking, packing).
- **Owner** — dashboard and all reports, read-only.

## Quantities

Stitched goods are entered as **dozens + pieces** (e.g. `2 dz 6 pc` = 30 pieces).
Cloth is entered in **meters** (up to 2 decimals). Money in **₹**.

## Updating the app (Admin)

When a new version is available, a banner appears at the top. Press **Update now**;
the app restarts itself in under a minute. If anything goes wrong it automatically
returns to the previous version — no data is ever lost.
