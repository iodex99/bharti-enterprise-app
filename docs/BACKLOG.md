# Backlog — known deferrals & accepted limitations

Reviewed each phase; promote to ROADMAP or implement when needed.

- **Rework of rejected pieces** — REJECTED stock is tracked but can only be written off in
  v1, not reissued for repair.
- **Multi-line purchase invoices** — one purchase row per model/color; a multi-item vendor
  invoice is entered as several purchases.
- **Downstream lineage is FIFO-approximate** — after cutting, physical pieces mix in bins;
  allocations record FIFO assumption, not physical certainty. Accepted for this domain.
- **Single company, single location** — no warehouse/branch dimension in v1.
- **No offline data entry** — PWA shell installs, but writes need the server reachable.
- **English only** in v1.
